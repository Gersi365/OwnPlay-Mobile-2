# Stage 13 visual-system source audit

Baseline source: `24b0d8fb49344f10c0833ae05068b10dcd7def43`
Working branch: `stage-13-visual-system-refactor`

## Trigger

Physical QA v19 showed that source-side polish did not match the approved OwnPlay visual direction. The observed Library build remained card-heavy and oversized, and VOD fullscreen remained dominated by large circular transport controls and a Material slider. Per the project visual acceptance contract, physical-device evidence overrides source-side assumptions.

## Audit conclusion

The mismatch was systemic rather than isolated. Repeated use of bordered panels, stock Material button geometry, filled category chips, oversized Continue Watching cards, poster metadata below artwork, settings-card repetition, and large fullscreen chrome caused the application to read as a generic Compose utility surface instead of an artwork-led cinematic media product.

## Stage 13 source target

This pass changes presentation only. Playback ownership, provider logic, Room, downloads state, secure credentials, backup format, navigation semantics, PiP ownership, and the Live Preview/fullscreen state machine are intentionally unchanged.

Source geometry targets for phone widths around 360–411 dp:

- top identity remains compact and media does not yield excessive vertical space to branding;
- bottom navigation is 64 dp before system navigation insets, with 24 dp icons and a 2 dp active rail;
- Continue Watching cards are 282 dp wide with a 154 dp artwork-led hero, compact progress, and two equal actions;
- Library posters are 132 dp wide with metadata integrated into the artwork rather than extending card height;
- provider categories use low-noise text/underline filtering instead of filled chip walls;
- Live channel rows use a subtle selected surface and narrow accent rail instead of full bordered cards;
- Live Preview remains transport-control-free and Now/Next is visually associated with the preview without another bordered panel;
- VOD fullscreen uses 48/56 dp touch targets with 40/50 dp visual circles, reduced scrims, a custom 3 dp seek track, and restrained secondary actions;
- Live fullscreen uses the same compact glass primitives and blue/black OwnPlay language;
- Settings removes permanent build-configuration chrome and presents sections as low-noise grouped surfaces rather than nested bordered preference cards;
- stock Material AlertDialog usage is replaced by an OwnPlay modal primitive.
