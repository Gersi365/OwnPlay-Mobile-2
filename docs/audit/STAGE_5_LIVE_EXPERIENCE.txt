# Stage 5 — Live Experience

## Purpose

Implement the user-approved Live experience on top of the validated Playback Foundation without crossing merge, release, signing, APK/AAB, or physical-QA boundaries.

## Authoritative Live contract applied

- Primary navigation remains exactly Live / Library / Settings.
- A different channel tap opens or updates Preview.
- Tapping the same previewed channel again enters fullscreen without reloading media.
- Back from fullscreen returns to the same Preview presentation.
- Back from Preview closes Preview and stops Live playback.
- Preview exposes no generic transport controls.
- Fullscreen remains video-first with a transient OwnPlay overlay.
- One existing process-wide PlaybackController is reused; Composables do not own independent players.
- Video target ownership is transferred through the Stage 4 Preview / Fullscreen target contract.
- EPG absence never blocks playback and is represented explicitly rather than with fabricated guide data.

## Implemented scope

- Added Live domain catalog/playback contracts.
- Added a pure Live presentation reducer and contract-centric JVM tests.
- Added Room-backed observation of available active-source channels while respecting hidden/local-name/local-logo/manual-order personalization.
- Added secure Live stream resolution:
  - M3U channels use the persisted resolved stream locator.
  - Xtream channels keep opaque provider stream identity in Room and reconstruct playback URLs only at playback resolution time using credentials from the credential store.
  - Resolved playback objects redact stream URIs from `toString()`.
- Added Live repository wiring to `OwnPlayServices`.
- Replaced the static Live shell preview with a real SurfaceView target bound to the shared PlaybackController.
- Added channel selection, Preview, same-channel fullscreen transition, Back transitions, transient fullscreen OwnPlay/LIVE overlay, and source/catalog empty states.
- Leaving Live through bottom navigation requests playback stop.
- No generic Media3 controller UI was introduced.
