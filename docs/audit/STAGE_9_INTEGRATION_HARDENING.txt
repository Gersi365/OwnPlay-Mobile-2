IMPLEMENTED
- Added Activity-level Picture in Picture integration driven by the persisted OwnPlay PiP preference.
- Declared MainActivity PiP support and handled orientation/screen-size configuration changes in place so fullscreen/PiP transitions do not require Activity recreation by default.
- Added pre-Android-12 guarded PiP entry from onUserLeaveHint and Android 12+ auto-enter eligibility through PictureInPictureParams.
- Added a pure PictureInPicturePolicy: entry requires PiP enabled, OwnPlay content fullscreen, a current media item, playWhenReady=true, a FULLSCREEN/PIP video target, and BUFFERING or READY playback.
- Added focused JVM tests for eligible ready/buffering playback and blocked disabled, paused, preview-target, missing-media, ended, and error states.
- Kept one process-wide PlaybackController and one ExoPlayer instance; PiP is a presentation destination, not a second playback session.
- Added PlaybackController.transferVideoTarget so FULLSCREEN <-> PIP ownership can change without reloading media or constructing another player.
- Hardened SurfaceView ownership with an attach-state listener that clears only the currently bound exact SurfaceView when it detaches.
- Removes the old detach listener before a replacement surface is installed, preventing a stale detached view from clearing a newer target.
- Backgrounding outside PiP pauses playback; foreground resumption occurs only when playback had previously been play-when-ready.
- Finishing the Activity requests a process-scope stop(clearMedia=true), avoiding reliance on a cancelling Activity lifecycleScope for final playback cleanup.
- Exposed OwnPlay fullscreen state from the Compose app shell to MainActivity while preserving the exact bottom-navigation contract: Live / Library / Settings.
- No Room entity/version/schema changes, source-provider schema changes, signing changes, or dependency changes were introduced in Stage 9.
